# RULES FOR WRITING CODE

- Use only uppercase letters for comments
- DO NOT write long comments, keep every comment short, write only where a comment is required.
- DO NOT use _ (underscore) prefixes for naming variables and functions 
- Modularity is the most important thing, DO NOT use provider specific terms. Each class/interface should be named after their job, not their provider or something.
- Every feature we build should be compatible with both windows and mac OS.
