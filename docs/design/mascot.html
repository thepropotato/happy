Happy — the mascot

The signed-off mascot on its own, so it can be worked on without the rest of the interface moving underneath it. This file is the reference the panel designs draw from.

Every state

One palette for all seven. The mouth is a lip band with a dark inside and two ball corners, and it stays a smile in every state — what changes is how wide it opens and what is going on around it. Only stopped leaves the palette, by draining out of it.

At the sizes it has to work

The same drawing at hero size, at the size it sits in the header once there are words to read, and at menu-bar size.
